# Версии FitApp

Номер версии — `version` в `frontend/package.json`, один для сайта и мобильного приложения. Сайт обновляется
при каждой выкладке, приложение в сторе — только с новой версией. Внизу экрана «Профиль» видно версию и сборку
клиента (сайт / Android-приложение) и сборку сервера — так понятно, отстаёт ли приложение на телефоне.

## 1.0.0 — 23.10.2026
- Первая версия в RuStore (в сторе — «1.0», versionCode 1): календарь, тренировки, договоры, запись клиентов,
  зарплатный отчёт, пуш-уведомления, удаление аккаунта.
- На сайте после неё: ссылка для нового пароля клиенту (FIT-71), «Предложить идею / Сообщить о проблеме» (FIT-73),
  продуктовые метрики (FIT-72), версия в профиле (FIT-74). В приложение попадут со следующей версией.
